## 固件 Release v1.4.0
### 🆕 新功能

- **跟随系统休眠**：响应上位机 `power_mode sleep/normal` 命令，自动关闭/恢复 LCD、LED、背光、传感器
- **屏幕旋转**：支持 0°/90°/180°/270° 运行时旋转，通过 `lcd_rotation` 串口命令控制
- **扩展性能数据**：新增 CPU 频率、内存已用/总计、显存已用/总计 5 个数据字段

### 🎨 UI 改进

- CPU 圆环内部新增频率显示
- GPU 圆环内部新增显存已用/总计
- 内存面板从柱状图改为进度条 + 数值显示
- 占用率动态变色：青绿(0-50%) → 黄(50-80%) → 红(80-100%)
- 温度动态变色：浅蓝(<80°C) → 浅红(≥80°C)

### 🔧 修复

- 修复休眠/旋转操作导致偶发的死机
- 修复 USB 持续连接时设备无法保持休眠（删除自动唤醒逻辑，休眠时丢弃性能数据）

### ⚠️ 注意事项
- 需配合上位机 v1.8.x 使用


## 上位机 Release v1.7.3
### 🆕 新功能

#### 跟随系统休眠
设备可随 Windows 电脑休眠自动息屏，唤醒后自动恢复。支持传统 S3 睡眠和 Modern Standby (S0)，设置页面提供开关控制。

#### 屏幕旋转
支持 0°/90°/180°/270° 四档旋转，设置页面下拉框选择后即时生效，连接时自动同步。

#### CPU 频率精准采集
新增 Windows PDH 性能计数器方案，解决 AMD Zen5 等新平台下 LHM 频率不准的问题，数据与任务管理器一致。

### 🎨 UI 改进

#### 上位机设置页面
- 两列并排布局，更紧凑

### 🔧 修复与优化

- 修复固件更新后由于启动时缺少等待时间而无法检测到版本号的问题
- 修复 USB 持续连接状态下设备无法保持休眠的问题
- 内存频率从 SPD 标称值改为实际 XMP/EXPO 运行频率

## ⚠️ 注意事项
- Windows 版本需要管理员权限以获取完整硬件监控数据
- "随电脑休眠"功能暂仅支持 Windows
- 本版本需配合固件 v1.4.0 使用

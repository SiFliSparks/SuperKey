## 固件 Release v1.4.2
### 🆕 新功能

- **跟随系统休眠**：响应上位机 `power_mode sleep/normal` 命令，自动关闭/恢复 LCD、LED、背光、传感器
- **屏幕旋转**：支持 0°/90°/180°/270° 运行时旋转，通过 `lcd_rotation` 命令控制
- **扩展性能数据**：新增 CPU 频率、内存已用/总计、显存已用/总计 5 个数据字段

### 🎨 UI 改进

- CPU 圆环内部新增频率显示
- GPU 圆环内部新增显存已用/总计
- 内存面板从柱状图改为进度条 + 数值显示
- 占用率动态变色：青绿(0-50%) → 黄(50-80%) → 红(80-100%)
- 温度动态变色：浅蓝(<80°C) → 浅红(≥80°C)

### 🔧 修复

- 修复休眠/旋转操作导致偶发的死机
- 修复 USB 持续连接时设备无法保持休眠（删除自动唤醒逻辑，休眠时丢弃性能数据）

### ⚠️ 注意事项
- 需配合上位机 v1.8.x 使用

## 上位机 Release v1.8.7
### 🆕 新功能

#### 跟随系统休眠
设备可随 Windows 电脑休眠自动息屏，唤醒后自动恢复。设置页面提供开关控制。

#### 屏幕旋转
支持 0°/90°/180°/270° ，设置页面下拉框选择后即时生效，（连接时）自动同步到设备。
- 屏幕旋转功能由`@！＇v＇！` 提议，感谢贡献！

#### CPU 频率精准采集
- 新增 Windows PDH 性能计数器方案，解决 AMD Zen5 等新平台下 LHM 频率不准的问题，数据与任务管理器一致。
- 多种性能监控方案自动适配，兼容更广泛的硬件平台。

### 🎨 UI 改进
- 优化设置界面板块布局，针对新功能增加操作项

### 🔧 其他修复与优化
- 修复固件更新的zip包检测逻辑，避免误报
- 修复固件更新后由于启动时缺少等待时间而无法检测到版本号的问题
- 修复 USB 持续连接状态下设备无法保持休眠的问题
- 内存频率从 SPD 标称值改为实际 XMP/EXPO 运行频率
- 解决软件内更新前无法完全关闭旧版本导致卡死等若干问题
- 解决在更新时无法保存自定义配置的问题
- 增强天气API板块提示文字
- 检测正在运行的实例，不允许多实例同时运行
- 天气API KEY添加明码显示
- 修复上位机正在运行时对上位机进行更新，flet UI 框架会卡死的问题
- 修正最小化弹窗的时机
- 设备连接运行时也可不断连修改端口，并保留手动断连功能
- 其他影响使用的问题

### ⚠️ 注意事项
- 本版本需配合固件 v1.4+ 使用
- 本次升级推荐先安装上位机，再下载固件，从上位机的固件更新功能一键升级（需要通过串口连接设备）
- 如遇部分项目无法使用，请：
- - 排查你使用的上位机和固件版本号是否互相匹配；
- - 确保设备已正确连接，如使用串口连接，需要安装CH340驱动；
- - 确保上位机获取到管理员权限（Windows）以正常工作；
- - 如使用USB连接，确保USB线和接口正常，必要时更换线材或接口；
- - 如问题依旧，请在QQ群728458583内提供详细的使用环境和操作步骤，以便进行进一步的排查和修复；

## 1.2   （已于2025年12月16日推送）
### 上位机Release v1.7.3
#### feature：
- 1、包管理器：添加uv作为包管理
- 2、灯光管理器，上位机通过对灯光颜色、亮度、预设效果的调节，实现对灯光的手动管理
- 3、windows使用nsis打包程序进行打包处理
- 4、新增固件一键烧录功能，可在上位机中直接对硬件进行bin文件烧录，实现一键更新
- 5、新增在每次成功连接(包含烧录完成后自动连接和断连后自动连接)后检测固件版本号
- 6、番茄钟任意状态下倒计时完成后，将有红色灯效提示，并且首页时钟板块从番茄钟与时钟内容互切自动变为时钟常显。
- 7、Mac体验。
#### fix:
- 1、字体：在Windows和Mac上面使用微软雅黑和苹方作为字体，解决字型错误问题
- 2、UI：删除不必要的提示文字，部分字体加粗显示，调整设置页面板块布局，修正不易观看的重点色，修正天气部分内容排布
- 3、固定窗口大小为1024x640，适配大多数分辨率的屏幕
- 4、自定义按键配置中对具体按键的配置现可直接从通过键盘输入，无需从菜单选择
### 固件Release v1.2.6
#### feature：
- 1、添加灯光管理器，该管理器通过对从上位机发来的预设指令的读取，进行灯光主题颜色的更换。
- 2、版本标记，固件需要响应上位机发来的版本请求，按照固定格式上传当前的版本信息。
- 3、小工具，替换原本的股票UI，实现下班倒计时、今天吃什么、随机数功能
- 4、新的硬件监控UI
#### fix：
- 1、修复在新的press逻辑中，函数只发送第一个组合键的问题，现在发送全部组合键之后，最后一组键实行长按逻辑
- 2、修复代码只使用了1个HID键位。每次发送新按键时，前一个按键的位置被清零的NKRO问题
- 3、将全局光效独立管理，消除单个按键绑定的光效对全局光效的影响


## 1.1（2025年12月9日，已推送）
### 上位机：
#### fix：
- 1、修改信息显示页面布局，将性能监控和天气数据这两大主要的小键盘数据放到一页中，删除已弃用的股票api显示板块
- 2、删除复杂的串口配置和数据显示窗口，将串口无需频繁更改的配置进行固定，将连接和数据下发开关集成到串口选择中，实现选择即连接，连接即启动数据下发。同时添加断开连接按钮。
#### feature：
- 1、添加自定义按键配置板块及其功能，实现每个按键单独配置自定义映射。
- 2、串口连接功能添加端口记忆与自动重连功能，实现在意外断连的情况下能够静默尝试重连
- 3、优化的API配置页面布局
- 4、添加应用设置功能，主要实现了关闭窗口是最小化到系统托盘和开机自动启动的功能。
### 固件：
#### feature：
- 1、添加自定义按键页面，配合上位机页面实现任意按键的自定义，并增加断电保存功能
#### fix：
- 2、优化性能监控页面显示，删除不必要的边框
- 3、优化交互逻辑，让KEY4与旋钮均可切换所有第一层级页面，并更改页面切换动画为从上向下推进
- 4、删除不必要的延时，在保证功能稳定的前提下，将开机速度从6秒缩短为3秒
